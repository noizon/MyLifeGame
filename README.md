## 📖 О проекте

**«Моя Жизнь»** — пошаговый симулятор жизни. Ты начинаешь как бомж с 0₽ на счету и должен пройти путь до миллионера.

**Что нужно делать:**
- 💼 Зарабатывать деньги
- 🏪 Покупать активы (кофейня, акции, недвижимость)
- 👨‍👩‍👧 Заводить семью
- 🎓 Получать образование
- ✈️ Путешествовать
- 🧾 Платить налоги
- 🏦 Брать кредиты (и не уходить в долги)

**Цель:** накопить миллион, купить яхту, стать легендой.

## 🎯 Геймплей

| Механика | Описание |
|---|---|
| ⏱️ Время | 1 ход = 1 неделя (4 хода = месяц, 48 ходов = год) |
| 💰 Экономика | Работа + активы дают доход |
| 🏪 Магазин | 13 активов: от спальника за 300₽ до клуба за 5 000 000₽ |
| 🏦 Банк | Кредиты от 1 000₽ до 5 000 000₽ под 20–60% |
| 🧾 Налоги | 0% → 13% → 20% → 25% → 30% |
| 👨‍👩‍👧 Семья | Жена и до 5 детей |
| 🎓 Образование | Вуз +15%, магистр +30%, PhD +50% |
| ✈️ Путешествия | 9 стран, каждая даёт +IQ и +счастье |
| 🏆 Достижения | 10 ачивок |
| ⚠️ Долги | Не платишь кредит — деньги в минус, приходят бандиты |
| 🎲 Случайные события | Работы, находки, свадьбы, ссоры, спорт, универ |

### Главы

| # | Название | Цель |
|---|---|---|
| 1 | 🚮 На дне | Купить телефон (1 000₽) |
| 2 | 🏚️ Первая работа | Открыть вклад (20 000₽) |
| 3 | 🏢 Малый бизнес | Купить кофейню / акции / квартиру |
| 4 | 💼 Империя | Купить магазин / ресторан / завод |
| 5 | 🏆 Миллионер | Купить небоскрёб / клуб / яхту |

## 🛠️ Технологии

- **Язык:** C# (.NET 9)
- **UI:** Windows Forms
- **Архитектура:** MVC + Service Layer
- **Сериализация:** System.Text.Json

### Паттерны

| Паттерн | Где |
|---|---|
| Strategy | Генерация событий |
| Factory | Создание событий по главам |
| Observer | Обновление UI |
| Repository | Сохранение/загрузка |
